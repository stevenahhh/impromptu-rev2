# 보고서 디자인 명세

## 형식

- 한국어 Markdown 원본과 독립 실행형 HTML 보고서를 함께 제공한다.
- 신청서의 공공기관 제안서 문맥을 따르되, 분석 보고서처럼 명료한 계층과 여백을 사용한다.
- HTML은 인쇄와 화면 읽기 모두에 적합해야 한다.

## 시각 언어

- 배경: `#F5F7FB`, 본문 표면: `#FFFFFF`, 진한 본문: `#182033`
- 주 강조: `#3157D5`, 보조 청록: `#0F8B8D`, 경고: `#B45309`, 위험: `#B42318`
- 글꼴: `"Pretendard", "Noto Sans KR", system-ui, sans-serif`
- 제목은 굵기 700, 본문은 400~500, 표·캡션은 12~14px를 사용한다.
- 카드와 표는 12px 반경, 1px 중성 테두리, 낮은 그림자로 구분한다.

## 정보 구조

1. 표지와 한 문장 결론
2. 신청서 요구 해석
3. 권고 아키텍처
4. 확장 디스플레이 흐름
5. 화면 복제/원격 콘솔 흐름
6. 실시간 AI·RAG 파이프라인
7. 보안·프라이버시
8. 기술 스택 비교와 단계별 권고
9. 위험·검증 계획
10. 출처와 방법론

## 그림 표준

- Mermaid/SVG는 원래 종횡비를 유지하고 `object-fit: contain` 방식으로 표시한다.
- 모든 그림은 제목, 범례 또는 캡션을 가진다.
- 색만으로 상태를 구분하지 않고 텍스트 라벨과 도형을 함께 사용한다.
- 긴 한국어 제목은 의미 단위 줄바꿈을 사용하고 한 글자 고아 줄을 허용하지 않는다.

## 접근성

- 본문 대비 4.5:1 이상, 큰 텍스트 3:1 이상을 목표로 한다.
- 표 헤더와 의미 구조를 HTML 요소로 표현한다.
- 링크 텍스트만 읽어도 목적을 이해할 수 있게 한다.
- 인쇄 시 배경과 테두리가 사라져도 정보 계층이 유지되어야 한다.
