# Impromptu 발표용 예상 질문

## 질의응답 메모

- **공용 화면에 내 자료가 그대로 나가나요?** 아니요. Stage에는 슬라이드 이미지만 표시됩니다. 근거 카드·질문·녹취는 발표자 Console에만 남습니다.
- **발표 중인데 근거가 없으면 어떻게 되나요?** 근거를 찾지 못하면 아무것도 추천하지 않습니다. 추측으로 채우지 않는 것이 정책입니다.
- **청중이 질문을 올릴 수 있나요?** 발표가 끝난 뒤 질의응답 창을 열 수 있습니다. 질문은 기록되어 리포트에 함께 남습니다.
- **초대 링크를 여러 명이 쓸 수 있나요?** 한 번만 쓸 수 있는 90초짜리 초대입니다. 화면 지문을 발표자가 눈으로 확인하고 승인해야 묶입니다.
- **발표를 다시 시작하려면?** 내 발표 목록에서 같은 덱을 이어서 준비하면 됩니다. 다시 업로드하지 않아도 됩니다.
- **삭제하면 어디까지 지워지나요?** 슬라이드·진행 상태·준비된 근거·리포트 접근까지 계정에서 제거됩니다.
