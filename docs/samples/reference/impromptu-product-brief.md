# Impromptu 제품 브리프

Impromptu는 발표 중 청중의 질문과 화면 흐름을 보고, 발표자 화면에만 근거 자료를 띄워 주는 발표 지원 도구입니다. 청중에게 보이는 공용 화면(Stage)에는 슬라이드만 나가고, 자료 카드·녹취·질문 같은 비공개 정보는 발표자의 Console에만 표시됩니다.

## 핵심 흐름

1. 발표자가 PPTX/PDF를 Console에 올리면 슬라이드가 공용 렌더로 변환됩니다.
2. 발표 중 말한 내용에서 검증 가능한 주장이 발견되면 미리 올려 둔 참고 자료와 대조해 근거 후보를 만듭니다.
3. 발표자가 근거를 승인해야만 공개됩니다. 청중 화면에는 발표자가 허용한 것만 나갑니다.
4. 발표가 끝나면 시간·슬라이드 체류·질문 기록이 정리된 발표 결과 리포트가 남습니다.

## 발표 포인트

- "업로드한 자료가 곧 근거입니다" — 참고 자료를 먼저 올리면 발표 중 추천이 그 자료에서 나옵니다.
- "공용 화면은 슬라이드뿐" — 근거 카드와 질문은 기본적으로 발표자만 봅니다.
- "종료하면 리포트" — 발표 결과 보기에서 진행 시간과 질문이 정리됩니다.
